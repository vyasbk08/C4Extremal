This project formalizes in Lean 4 using Mathlib the exact values of the Turán number of the 4 cycle for small graphs. For n = 3, 4, 5, 6 and 7 and it proves both that a graph with the maximum number of edges exists without a 4 cycle and that adding one more edge always creates one. The problem is the toy version of the extremal questions studied by Axiom Math’s open source tool Axplorer.
